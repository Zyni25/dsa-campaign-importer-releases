# DSA Campaign Importer – Installationspakete

Hier werden künftig **freigegebene Installationspakete** des Foundry-VTT-Moduls **DSA Campaign Importer** veröffentlicht.

## Status
**Noch keine öffentliche Modulversion freigegeben.** Der Quellstand `0.1.0` wurde bereits in einer separaten Foundry-Testwelt in wesentlichen Funktionen geprüft. Das Release-Paket und die Update-Adressen werden erst nach technischer Prüfung bereitgestellt.

## Geplanter Installationsweg
1. Nach der ersten Freigabe erscheint hier der Link zur `module.json` (Manifest-URL).
2. In Foundry bzw. The Forge kann diese URL zur Installation verwendet werden.
3. Künftige Updates werden über die im Modulmanifest hinterlegten, öffentlich erreichbaren URLs bereitgestellt.
